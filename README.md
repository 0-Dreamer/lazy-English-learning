# ПравоПисьмо — тренажёр английских слов (Spelling Trainer)

Веб-приложение для запоминания написания английских слов, тренировки орфографии и грамматики.

## Возможности
- Посимвольный ввод английского текста с мгновенной подсветкой: **зелёный** — правильная буква, **красный** — ошибка
- Интерактивный словарь: клик по любому слову открывает всплывающее окно со всеми его значениями (с учётом контекста текущего предложения)
- Полный перевод каждого предложения справа
- Кнопка «Подробнее: как построено предложение» с разбором грамматических правил
- Более 1000 заданий (одиночные предложения, диалоги, мини-истории) по 24 темам и 4 уровням сложности
- Сохранение прогресса в `localStorage` (прогресс остаётся при закрытии браузера)
- Адаптивный дизайн для мобильных устройств и десктопов

## Как развернуть на Vercel (Бесплатно за 1 минуту)

### Вариант 1: Через GitHub и Vercel Web Dashboard (Самый простой)
1. Создайте новый репозиторий на [github.com](https://github.com/new).
2. Склонируйте или загрузите файлы проекта в ваш репозиторий.
3. Откройте [vercel.com/new](https://vercel.com/new).
4. Нажмите **Import** напротив вашего репозитория.
5. Нажмите **Deploy**. Vercel автоматически определит Next.js и развернёт сайт за 30 секунд.
6. Вы получите постоянный домен вида `https://your-project.vercel.app`.

### Вариант 2: Через Vercel CLI (через терминал)
```bash
npm i -g vercel
vercel login
vercel
```
Следуйте подсказкам в терминале (выберите настройки по умолчанию).
